Environment Setup

Set these environment variables on the demo-wall Deployment so credentials appear on this page and the Demo Wall. The secrets are read at startup; restart the pod after patching.
VariableRequired forHow to get it
KOMMANDER_SSO_USERNAME Kiali, Jaeger, Grafana, Kommander Typically admin. Confirm with your Kommander SSO config.
KOMMANDER_SSO_PASSWORD Kiali, Jaeger, Grafana, Kommander kubectl -n kommander-default-workspace get secret dex-k8s-authenticator-secret -o jsonpath='{.data.client_secret}' | base64 -d
or check your cluster's SSO secret.
ARGOCD_USERNAME ArgoCD Defaults to admin if unset.
ARGOCD_PASSWORD ArgoCD kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath='{.data.password}' | base64 -d
KOMMANDER_PLATFORM_BASE Kommander URL auto-discovery Optional. If the Kommander URL shows wrong, override with https://<cluster-hostname> (the sslip.nutanixdemo.com hostname).
JAEGER_QUERY_URL Storefront trace deep-links Set on the storefront Deployment (not demo-wall). Use the Jaeger UI URL from Platform Access above.
Create (or update) the demo-wall-access Secret — credentials are read from here at pod startup: 
kubectl -n demo-ops create secret generic demo-wall-access \
  --from-literal=kommander_username=admin \
  --from-literal=kommander_password='<password>' \
  --from-literal=argocd_username=admin \
  --from-literal=argocd_password='<password>' \
  --dry-run=client -o yaml | kubectl apply -f -
kubectl -n demo-ops rollout restart deployment/demo-wall
